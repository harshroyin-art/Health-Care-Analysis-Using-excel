# Health-Care-Analysis-Using-excel
This project involves end-to-end data analysis of hospital records using Microsoft Excel. The dataset includes patient details such as age, gender, blood type, medical condition, admission type, billing amount, insurance provider, and recovery duration.

🎯 Project Objective

The goal was to transform raw healthcare data into an interactive dashboard that enables stakeholders to monitor patient demographics, medical conditions, billing performance, insurance distribution, admission trends, and recovery outcomes.

🔍 Key Insights

✅ Patients aged 53–62 years represented the highest number of diabetes cases.

✅ Medical conditions showed a steady increase between 2019 and 2023, highlighting changing healthcare demand.

✅ Emergency admissions generated the highest billing amounts, emphasizing their impact on hospital revenue.

✅ Revenue was well distributed across multiple insurance providers, reducing dependence on a single payer.

✅ Recovery outcomes varied across medical conditions, providing opportunities to improve treatment effectiveness and patient care.

📈 Business Value

This project demonstrates how data can be transformed into actionable insights that help healthcare organizations:

Monitor operational performance
Track financial metrics
Improve resource allocation
Support evidence-based decision-making
